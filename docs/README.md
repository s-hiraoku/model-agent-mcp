## 記述の読み方

- **採用した設計**: このプロジェクトで守る責務と構成。
- **実装済み**: 現在のコードに存在し、ローカルのテストで確認できる機能。
- **未検証**: 実際の OAuth アカウント、Cursor Cloud Agent、公開 HTTPS 経路でまだ動作確認していない部分。
- **検討案**: 壁打ち中に出たが、現行 PoC には採用していない方式。

会話の要約は設計判断を読み返せるように編集した記録です。過去の回答をそのまま製品仕様や実動作の証明として扱っていません。外部サービスの現在の設定は、各文書にリンクした公式資料と実環境で再確認してください。
